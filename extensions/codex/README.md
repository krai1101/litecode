## Using Codex in LiteCode

Codex helps you understand a workspace, plan changes, and edit files from LiteCode. Open **Codex** in the secondary sidebar, sign in with ChatGPT or use an OpenAI API key, then start a chat.

- Attach files or images with **+**. Use **Include active file or selection** to share the editor context.
- Choose an approval mode from the composer. When Codex requests approval, review the action before allowing it.
- When a response lists edited files, select a file or choose **View changes** to review the diff in the editor.
- Open **History** to continue a previous chat.
