# OpenAI Blossom

The white Blossom SVG is the original asset from OpenAI's Codex VS Code
extension `openai.chatgpt-26.1007.21434-win32-x64`,
`resources/blossom-white.svg`. `codex.svg` preserves its path geometry on a
transparent background with a neutral foreground. Activity navigation uses the
workbench's theme foreground color.

The mark belongs to OpenAI. It identifies the OpenAI service integration, not
LiteCode's own branding or an endorsement of LiteCode. It is not covered by
LiteCode's software license. See [OpenAI's brand guidelines](https://openai.com/brand/)
and [terms](https://openai.com/policies/row-terms-of-use/).

`codex-home.svg` preserves the Codex mark geometry from the same OpenAI extension
version `26.1021.22027`, `webview/assets/codex_new-f14177b03534.svg`.
Only the overall opacity is reduced for the empty-state watermark.
The OpenAI mark and terms above also apply to this asset.
